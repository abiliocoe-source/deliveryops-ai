# Two-minute demo

1. Run `streamlit run app.py`. The header says the data is fictional.
2. On **Overview**, read the sentence under the title, then the KPI strip. The weekly late rate rises over the six months and Pizza has the highest late rate. Say that both patterns come from the data generator, not from a real kitchen.
3. In the sidebar, pick one category and a shorter date range. Everything recalculates.
4. Upload a CSV with a missing column to show the error message. Then upload the sample with one broken row to show the "rows removed" warning.
5. Open **Insights**: facts, hypotheses and recommendations, each with its evidence. Point out that hypotheses are never stated as causes.
6. Download the Markdown report. Open **Time saved** and note the estimate label.
7. Mention that no API key is needed, and that the optional LLM summary is rejected if it brings numbers that aren't in the evidence.
