# 2-minute demo script
1. (0:00) `streamlit run app.py`. Point out the caption: data is SYNTHETIC/FICTIONAL.
2. (0:20) Dashboard: KPIs, late rate over time (rising), by category (Pizza highest). Say these patterns come from the generator.
3. (0:50) Filters: pick one category and a date range; KPIs update.
4. (1:05) Upload a CSV with a missing column, show the clear error; then the sample CSV with a bad row, show the warning.
5. (1:25) Insights tab: facts / hypotheses / recommendations with evidence; stress that hypotheses are not causal claims.
6. (1:45) Export the Markdown report; open Savings tab, note the ESTIMATE label.
7. (1:55) Mention: no API key needed; LLM is optional and its numbers are checked.
